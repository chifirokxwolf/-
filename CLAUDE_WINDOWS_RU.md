# Первый вход в Claude на Windows

**При бесконечной проверке Cloudflare в Chromium используйте
[новый ручной запуск Chrome/Edge](CLAUDE_MANUAL_LOGIN_RU.md).** Установленный
браузер открывается без Playwright, с отдельным профилем. Архив для этого шага:
[`claude-windows-login-0.3.1.zip`](https://github.com/chifirokxwolf/-/raw/refs/heads/main/dist/claude-windows-login-0.3.1.zip).
Ниже сохранены инструкции к первоначальному инструменту 0.3.0.

Для подключения нужны работающий Cardinal на Windows, Python из его установки,
доступ к `claude.ai` с этого компьютера и один ваш тестовый аккаунт с почтой/Remail.
Первый вход выполняется в видимом браузере. Если сервис запросит подтверждение,
вы проходите его вручную. Коды, cookies и профиль браузера присылать не нужно.

**Это подготовка сессии, а не готовый Claude-адаптер.** После неё ещё нужно
проверить реальный интерфейс лимитов и глобальный отзыв, затем реализовать и
подключить адаптер. Поле `claude_provider_file` пока оставьте пустым.

## Установка и первый вход

1. Скачайте `dist/claude-rental-plugin-0.3.0.zip` и распакуйте в папку Cardinal,
   рядом с `main.py`. Сохраните структуру: `plugins/` и `tools/` должны быть
   непосредственно в папке Cardinal. Плагин обновите по `INSTALL_PLUGIN_RU.md`.
2. Один раз запустите **`tools/setup_claude_browser.cmd`**. Он установит Playwright
   и Chromium через тот же `python`, которым `Start.bat` запускает Cardinal.
   Если у вас собственное виртуальное окружение, выполните в нём вручную:

   ```powershell
   python -m pip install "playwright>=1.49,<2"
   python -m playwright install chromium
   ```

3. В Telegram откройте **`/claude_rental → Аккаунты`** и запомните числовой ID
   тестового аккаунта. На нём не должно быть действующего покупателя.
4. Запустите **`tools/open_claude_session.cmd`** и введите этот ID. Откроется
   отдельный Chromium. Войдите в нужный аккаунт по его почте и коду из Remail.
   Это вход владельца, он не расходует будущую выдачу покупателю в базе плагина.
5. После успешного входа вернитесь в консоль и нажмите Enter: браузер закроется.
   Снова откройте инструмент с тем же ID и проверьте, что вход сохранился.

Профиль находится в
`storage/claude_rental/browser_profiles/<ID>/owner/`. Каждый аккаунт получает
отдельный профиль. Не выбирайте личный профиль Chrome и не открывайте один
профиль одновременно в нескольких процессах. Храните папку на этом компьютере;
она содержит действующую сессию. Инструмент ничего не отправляет в GitHub.

## Что проверить после входа

- В настройках использования найдите реальные лимиты за 5 часов и 7 дней:
  названия показателей, проценты, сроки сброса, дополнительные недельные ограничения.
- В настройках аккаунта найдите **«Выйти везде»** и его точное название на языке
  этого аккаунта. Для привязки нужны видимые элементы реальной страницы.
- Для проверки отзыва откройте тот же тестовый аккаунт во втором независимом
  браузере. После глобального выхода он должен потерять доступ. Этот шаг
  выполняйте только на тестовом аккаунте без действующей аренды.
- Если продаётся Claude Code, его авторизацию надо проверить отдельно после
  глобального выхода. Выход браузера сам по себе не доказывает отзыв Code-токенов.

Для следующего шага достаточно сообщить: сохранился ли вход после повторного
запуска, язык интерфейса, какие показатели есть в разделе лимитов и точный текст
кнопки глобального выхода. Для просмотра страницы можно показать скриншоты
разделов лимитов и аккаунта с закрытыми почтой и личными данными. Не передавайте
сетевые дампы, cookies, коды входа, персональные ссылки Remail или папку профиля.

Для будущей автоматизации компьютер с Cardinal должен работать постоянно.
Во время сна или выключения проверки срока и отзыв доступа не выполняются.
На этом этапе ни открытие профиля, ни установка браузера не включают автовыдачу.

Инструмент сохранения профиля проверяется локально в Chromium. Установка
`.cmd` на Windows и авторизация настоящего Claude требуют проверки на вашем ПК.
