# Установка Claude Rental

Актуальная версия **0.3.2** устанавливается как один плагин через Telegram-бота Cardinal.

1. Скачайте файл [`dist/claude_rental_plugin.py`](dist/claude_rental_plugin.py).
2. Отправьте своему боту Cardinal команду `/upload_plugin`, затем файл как документ.
3. Выполните `/restart`.
4. Откройте `/claude_rental` или **Плагины → Claude Rental → Настройки**.
5. Через меню добавьте аккаунты, настройте отправителей писем и параметры лота.

**Полная инструкция:** [INSTALL_PLUGIN_RU.md](INSTALL_PLUGIN_RU.md).

Обновление с 0.1.0: сохраните базу и настройки в `storage/claude_rental/`,
замените файл плагина при остановленном Cardinal и переместите прежние
`plugins/rental.py` и `plugins/remail.py` за пределы папки плагинов.
Новая сборка содержит эти модули внутри. Не устанавливайте две копии плагина.

Управление аккаунтами и клиент Remail реализованы. Полная автоматическая
аренда требует ещё не реализованного адаптера Claude для входа, лимитов
и завершения сессий. Без него выдача блокируется, а меню остаётся доступным.
