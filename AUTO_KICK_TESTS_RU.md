# Проверка выпуска Claude Rental 0.4.2

Итоговый полный прогон: **151 тест прошёл, ошибок и пропусков нет**.
Команда: `CARDINAL_SOURCE=/tmp/cardinal-validation-042 RUN_BROWSER_TESTS=1 /workspace/claude-validation-venv/bin/python -m unittest discover -v`.
Время итогового прогона — 49,247 с. До добавления последней регрессии
также прошёл полный прогон из 150 тестов.

- Все 18 проверок интеграции Cardinal выполнены. Стенд — публичный форк
  `sidor0912/FunPayCardinal` на ревизии `c09dd13be25072bb3d5cdbba33d1e0d70e477710`,
  поверх которого скопированы 18 корневых файлов из пользовательских вложений.
  Telegram, FunPay и почтовые сетевые вызовы подменены; сообщения не отправлялись.
- Регрессия воспроизводила `label_changed_during_read` до исправления:
  после измерения подписи страница вставляет новые элементы перед ней.
  Теперь подпись и значение извлекаются в одном браузерном вызове.
- Проверены русский ID организации, поле только для чтения, задержка значения,
  скрытые дубли, текст чата вне настроек и непрерывная перерисовка строк лимитов.
  Проверены пары 0/0, 0/100, 100/0, 100/100 и дробные проценты.
- В настоящем Chromium проверены русская строка глобального выхода с отдельной
  кнопкой «Выйти», подтверждение, вставка другой кнопки во время поиска,
  прямой переход после выхода и отказ при неподтверждённом отзыве сессии.
  Отдельный итоговый прогон действий браузера: 14 тестов прошли.
- Отдельный прогон восстановления профиля и динамических страниц: 13 тестов
  прошли. Закрытие через CDP проверено на отдельном нативном процессе Chromium:
  второй браузер остаётся подключённым, данные профиля сохраняются после запуска.
- Авто-кик, сроки, продление, перезапуск, блокировки, повтор после ошибки и
  сохранение результата испытаны на временных SQLite-базах. В полном прогоне
  однофайловый плагин запускается из чистого каталога в `python -I`.
- Проверены сохранение полной ссылки `magic-link#...` и отказ для чужого домена.
  Проверка аккаунта распознаёт незавершённый вход и не выдаёт фиктивные лимиты.

Среда: Linux, Python 3.12, Playwright 1.62, Chromium. Windows-запуск проверяется
имитацией системных вызовов; настоящего Windows и авторизованного Claude здесь
нет. Тесты локальных страниц не подтверждают успешный вход на сервере Claude,
отзыв Claude Code или невозможность повторного входа по старой ссылке.
Аккаунт после браузерного авто-кика остаётся в cleanup, автоматическая повторная
выдача не включается.

# Проверка выпуска Claude Rental 0.4.0

Проверки выполнены на Python 3.12.14, Playwright 1.62.0 и Chromium в Linux.

- Общий прогон: `RUN_BROWSER_TESTS=1 python -m unittest discover -v`.
  Обнаружено 126 тестов: 108 прошли, 18 пропущены.
- Пропущены тесты полной интеграции Cardinal: нужен полный каталог через
  `CARDINAL_SOURCE`. Вложения содержат корневые файлы, но не FunPayAPI, tg_bot,
  Utils и locales. Пропуски не засчитываются как успешные проверки.
- Дополнительно использован настоящий метод `Cardinal.load_plugin` из
  приложенного пользователем `cardinal.py`: однофайловый плагин загрузился,
  обязательные поля доступны, Runtime и SQLite инициализируются.
- Готовый однофайловый плагин испытан в отдельном процессе `python -I` в чистом
  каталоге без исходных helper-модулей. Проверены фоновый поток, пауза продаж,
  занятый замок выдачи, сохранение результата и перезапуск.
- Повторный целевой прогон: `RUN_BROWSER_TESTS=1 python -m unittest test_auto_kick -v`.
  21 тест авто-кика проверяет SQLite, границу срока, продление, повторное событие,
  истёкшую выдачу, перезапуск, ошибки, задержку повторов, блокировку параллельной
  работы, неправильную привязку и независимость разных аккаунтов.
- Chromium исполняет настоящие действия по локальным HTML-страницам:
  открытие настроек, отложенный диалог подтверждения, глобальный выход,
  проверку прежней авторизации в отдельном контексте. Ответы сайта подменяются
  локально. Тест обнаруживает простое удаление cookies без отзыва сессии,
  чужую организацию, HTTP-ошибку и обрыв после нажатия.

В первом прогоне найден и исправлен переход на настройки без полной загрузки:
проверка теперь делает reload, если goto вернул переход внутри документа.
Повторные прогоны относятся к исправленной версии.

Реальный отзыв пользовательских сессий Claude и токенов Claude Code здесь не
проверен: авторизованного аккаунта нет. Успех локального стенда не является
такой проверкой. После подтверждённого браузерного выхода аренда остаётся в
cleanup, аккаунт не возвращается автоматически в выдачу.
