# Проверка выпуска Claude Rental 0.4.0

Проверки выполнены на Python 3.12.14, Playwright 1.62.0 и Chromium в Linux.

- Общий прогон: `RUN_BROWSER_TESTS=1 python -m unittest discover -v`.
  Обнаружено 126 тестов: 108 прошли, 18 пропущены.
- Пропущены тесты полной интеграции Cardinal: нужен полный каталог через
  `CARDINAL_SOURCE`. Вложения содержат корневые файлы, но не FunPayAPI, tg_bot,
  Utils и locales. Пропуски не засчитываются как успешные проверки.
- Дополнительно использован настоящий метод `Cardinal.load_plugin` из
  приложенного пользователем `cardinal.py`: однофайловый плагин загрузился,
  обязательные поля доступны, Runtime и SQLite инициализируются.
- Готовый однофайловый плагин испытан в отдельном процессе `python -I` в чистом
  каталоге без исходных helper-модулей. Проверены фоновый поток, пауза продаж,
  занятый замок выдачи, сохранение результата и перезапуск.
- Повторный целевой прогон: `RUN_BROWSER_TESTS=1 python -m unittest test_auto_kick -v`.
  21 тест авто-кика проверяет SQLite, границу срока, продление, повторное событие,
  истёкшую выдачу, перезапуск, ошибки, задержку повторов, блокировку параллельной
  работы, неправильную привязку и независимость разных аккаунтов.
- Chromium исполняет настоящие действия по локальным HTML-страницам:
  открытие настроек, отложенный диалог подтверждения, глобальный выход,
  проверку прежней авторизации в отдельном контексте. Ответы сайта подменяются
  локально. Тест обнаруживает простое удаление cookies без отзыва сессии,
  чужую организацию, HTTP-ошибку и обрыв после нажатия.

В первом прогоне найден и исправлен переход на настройки без полной загрузки:
проверка теперь делает reload, если goto вернул переход внутри документа.
Повторные прогоны относятся к исправленной версии.

Реальный отзыв пользовательских сессий Claude и токенов Claude Code здесь не
проверен: авторизованного аккаунта нет. Успех локального стенда не является
такой проверкой. После подтверждённого браузерного выхода аренда остаётся в
cleanup, аккаунт не возвращается автоматически в выдачу.
