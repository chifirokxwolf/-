# Claude Rental 0.3.4 для FunPay Cardinal 0.1.17.15

В 0.3.4 исправлен порядок подтверждения профиля и добавлены этапы и время
в отчёт проверки браузера. Для этой проверки достаточно обновить папку tools
из отдельного архива, как описано в `CLAUDE_BROWSER_CHECK_RU.md`.

В 0.3.3 исправлен поиск подтверждения «Выйти везде» поверх окна Settings.
Добавлена отдельная проверка чтения лимитов из профиля Edge/Chrome:
`CLAUDE_BROWSER_CHECK_RU.md`. Эта проверка не включает автоматические продажи.

В обновлении: точные сроки пяти лотов, умножение на количество, продление того же
аккаунта, память покупателей, один бонусный час за отзыв к первой покупке,
напоминание за 15 минут и приветствие с почтой перед однократной выдачей кода.

**Вход в Claude, чтение реальных лимитов и проверенный выход всех сессий ещё
требуют Claude-адаптера.** Эта сборка реализует правила продаж, меню и Remail,
но без адаптера не включает автоматическую выдачу. Браузерный помощник для
«Выйти везде» включён в сборку и проверен на локальных страницах разных языков;
он ещё не подключён к настоящему аккаунту. План: `CLAUDE_AUTOMATION_PLAN.md`.
Для Windows в архив включены инструменты первого входа с сохранением профиля;
инструкция находится в `CLAUDE_WINDOWS_RU.md`. Это подготовка к будущему адаптеру.

## Скачать и установить

- [ZIP с плагином и инструкцией](https://github.com/chifirokxwolf/-/raw/refs/heads/main/dist/claude-rental-plugin-0.3.4.zip).
- [Готовый Python-файл](https://github.com/chifirokxwolf/-/raw/refs/heads/main/dist/claude_rental_plugin.py).

1. Сохраните резервную копию `storage/claude_rental/` при остановленном Cardinal.
2. Распакуйте ZIP. Нужный файл — **`plugins/claude_rental_plugin.py`**.
3. Откройте своего Telegram-бота Cardinal как администратор, выполните
   `/upload_plugin` и отправьте этот `.py` как документ с прежним именем.
   ZIP целиком команда не принимает. При обновлении замените прежний файл.
4. Выполните `/restart`, затем **`/claude_rental`**.
5. В заголовке должно быть **Claude Rental 0.3.4**. Меню также доступно через
   **Плагины → Claude Rental → Настройки**.

Можно заменить файл вручную в папке `plugins/` при остановленном Cardinal.
Не устанавливайте две копии под разными именами. UUID плагина остаётся прежним.
Одноимённый файл в корне GitHub — исходник; готовая сборка находится в `dist/`.
Она включает все модули внутри, дополнительные файлы Python не нужны.
При обновлении с исходной версии 0.1.0 переместите старые `plugins/rental.py`
и `plugins/remail.py` за пределы папки плагинов.

Базу и настройки удалять не нужно. Миграция добавляет историю покупателей,
покупок, бонусов и напоминаний, сохраняя аккаунты и аренды. Старое стандартное
правило на 5 часов автоматически заменяется пятью стандартными правилами.
Если вы вручную меняли названия, ваши правила сохраняются; для пяти новых
сроков нажмите **Лоты и сроки → Заменить правила на 5 стандартных**.
При обновлении старых правил включается умножение срока на количество.

## Что означает меню

| Кнопка | Назначение |
| --- | --- |
| **Аккаунты** | Почта, состояние, последние известные лимиты, текущий заказ. Откройте аккаунт для проверки Remail или исключения из новых выдач. |
| **Добавить аккаунт** | Сначала точная почта, затем целая персональная ссылка Remail. |
| **Аренды** | Последние 20 аренд, их состояние и время окончания по Москве. Продление меняет срок существующей аренды. |
| **Отправители Claude** | Разрешённые адреса из поля **«От кого»** настоящего письма входа Claude. Это не почта аккаунта и не ссылка Remail. |
| **Лоты и сроки** | Пять правил, их названия и сроки; можно добавить свой лот. Заменяет старые кнопки «Название лота» и «Срок аренды». |
| **Проверить название** | Вставьте название: бот покажет срок одной единицы без покупки, выдачи кода и начисления бонуса. |
| **Пауза / запуск** | Приостановить или разрешить обработку новых покупок, включая продления. Активные аренды продолжают обслуживаться. Без адаптера запуск заблокирован. |
| **Обновить** | Заново показать состояние панели. |
| **Справка** | Краткое объяснение настроек. |

Надпись **«Новые выдачи: на паузе»** означает, что новые покупки не исполняются.
**«Не подключён Claude-адаптер»** объясняет, почему одной почты пока недостаточно
для запуска автоматической аренды. **«Сейчас: не заданы»** в разделе отправителей
означает пустой список допустимых отправителей писем, а не отсутствие аккаунта.

### Почта и отправитель

1. Нажмите **Добавить аккаунт**, введите почту и персональную ссылку.
   Поддерживаются `remail.best` и `remail.aishop6.com`, обычные, Markdown-ссылки
   и скрытые ссылки Telegram. Почта должна совпадать с параметром `email` в ссылке.
2. В **Аккаунты → нужный аккаунт → Проверить Remail** бот покажет число писем
   и найденные адреса отправителей, без содержимого писем и кодов.
3. Выберите адрес именно настоящего письма входа Claude и укажите его в
   **Отправители Claude**. Несколько адресов разделяются запятой. Не добавляйте
   всех найденных отправителей. После изменения перезапустите Cardinal,
   если адаптер уже подключён.

Токен берётся из параметра `token` ссылки, дополнительный API key для этих
почтовых методов не нужен по предоставленной документации. API-запрос идёт
на исходный домен ссылки. Покупателю не передаются ссылка Remail и её токен.
Сообщение со ссылкой удаляется по возможности, но это обычный личный чат Telegram.

### Точные сроки и количество

| Фрагмент названия | За одну единицу | За две единицы |
| --- | --- | --- |
| Аренда 30 минут | 30 минут | 1 час |
| НА 1 ЧАС | 1 час | 2 часа |
| НА 2ЧАСА | 2 часа | 4 часа |
| НА 3 ЧАСА | 3 часа | 6 часов |
| НА 5 ЧАСОВ | 5 часов | 10 часов |

Бонус в названии и число `5.5` в `OPUS 5.5` не входят в оплаченный срок.
Для своих лотов укажите полное название и срок, например `30 мин`, `1 час`
или `90` (число без единицы означает минуты). Неоднозначные правила и неизвестные
сроки не исполняются автоматически. Проверьте все используемые названия кнопкой
**Проверить название**. При смене срока стандартного правила измените и название.

### Покупатели, отзывы, продление

Покупатель узнаётся по постоянному ID FunPay; смена имени не сбрасывает историю.
Первой считается первая покупка подходящего лота, записанная в этой базе.
Существующие аренды старой версии учитываются при обновлении. Продажи,
совершённые до установки и отсутствующие в базе, автоматически не импортируются.

Приветствие приходит первым и содержит почту, оплаченный срок и предупреждение,
что код/ссылка выдаётся только один раз на аренду. Затем приходит отдельное
сообщение с кодом/ссылкой. Таймер начинается после подтверждённой отправки.

За отзыв к первой покупке начисляется **ровно +1 час один раз**. Бот проверяет
настоящий отзыв через FunPay; фразы покупателя «я оставил отзыв» недостаточно.
Покупатель предупреждён: **оставьте отзыв сразу; бот должен подтвердить его до
конца первоначального срока аренды, иначе бонус не начисляется**. Продление
не увеличивает окно для бонуса. Поздний отзыв не переносит час на следующую
покупку, редактирование отзыва не даёт новый час.

За 15 минут до окончания бот напоминает о сроке и предлагает продление.
Если покупатель до окончания аренды снова оплачивает подходящий лот, срок
добавляется к её текущему окончанию на том же аккаунте. Например: оставалось
20 минут, куплены две единицы лота «1 час» — остаётся 2 часа 20 минут.
Новый код не выдаётся. Событие повторного заказа повторно время не прибавит.
После продления или бонуса напоминание переносится на новый срок. Покупка,
которую бот получил уже после истечения аренды, оформляется как новая аренда.

## Данные и ограничения работы

Данные создаются в `storage/claude_rental/config.json` и
`storage/claude_rental/rentals.sqlite3`. В базе лежат секретные токены Remail;
ограничьте доступ к серверу и резервным копиям. Меню доступно только
администраторам Cardinal в личном Telegram-чате.

Новый аккаунт остаётся в `quarantine`, пока адаптер не подтвердит отзыв старого
доступа и реальные лимиты. При любом лимите больше 70%, неизвестных или устаревших
данных новая аренда запрещена. Рост лимитов не обрывает оплаченную аренду.
Продление сохраняет тот же аккаунт, включая уже израсходованный лимит.
Возврат в пул после аренды требует подтверждённого отзыва доступа и проверки
лимитов. Ручной возврат в пул не обходит эти условия.

Укажите путь к реализованному и проверенному Claude-адаптеру в
`claude_provider_file` и перезапустите Cardinal. Контракт описан в `README.md`.
Токен Remail не заменяет адаптер. Реальные входы, проценты и успех выхода не имитируются.
Отключите штатную автовыдачу Cardinal на тех же лотах и запускайте один экземпляр
плагина на базу.

Напоминания проверяются каждые 30 секунд; отзывы — по событию и дополнительно
раз в минуту, до пяти заказов за проход. Остановка Cardinal прекращает проверки.
Напоминания помечаются до сетевой отправки, поэтому сбой может привести к
пропуску сообщения, но не повторной рассылке. Ошибки видны в панели. Начисленные
продления и бонусы сохраняются даже при ошибке отправки уведомления.

Пауза сохраняет обслуживание начатых аренд, но новые покупки и продления во
время паузы требуют ручной проверки. Отключение самого плагина прекращает
фоновые проверки. Очередь не восстанавливается после остановки; возвраты,
нехватка аккаунтов и неясный результат выдачи требуют вмешательства оператора.
Внешние операции Claude пока последовательны: фактический отзыв сессий может
задержаться на время текущего запроса или ожидания письма. Это не мгновенный кик.

## Проверки для разработчика

Загрузка, меню и события проверяются на предоставленном Cardinal 0.1.17.15.
Тесты используют его реальные классы, а сетевые действия заменяют имитацией.
Полная цепочка с настоящими FunPay, Remail и Claude ещё не проверена.

```sh
python build_plugin.py
python -m unittest -v test_remail test_rental test_sales
CARDINAL_SOURCE=/path/to/FunPayCardinal python -m unittest -v test_cardinal_integration
```

Для последней команды нужны зависимости Cardinal. Проверки браузерного
помощника требуют Playwright и Chromium и запускаются отдельно:
`RUN_BROWSER_TESTS=1 python -m unittest -v test_claude_browser_actions`.
