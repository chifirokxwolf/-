# Claude Rental 0.2.0 для FunPay Cardinal 0.1.17.15

Это плагин с меню в Telegram. Работа с аккаунтами и почтовым API Remail доступна
сразу после установки. Полная автоматическая аренда по-прежнему требует отдельно
реализованного Claude-адаптера: вход, реальные лимиты и завершение всех сессий.
Без этого адаптера кнопка включения выдачи объясняет причину отказа.

## Установка через Telegram

1. Скачайте **`dist/claude_rental_plugin.py`** из репозитория. Это готовая сборка
   со всеми модулями внутри. Одноимённый файл в корне — исходник для разработки.
2. Откройте своего Telegram-бота Cardinal и авторизуйтесь как администратор.
3. Выполните `/upload_plugin` и отправьте скачанный `.py` как документ.
4. Перезапустите Cardinal командой `/restart`.
5. Выполните **`/claude_rental`** либо откройте
   **Плагины → Claude Rental → Настройки**.

Альтернатива: остановите Cardinal, скопируйте готовый `.py` в его папку `plugins/`
и запустите Cardinal обычным способом. ZIP `dist/claude-rental-plugin-0.2.0.zip`
содержит готовую папку `plugins/` и эту инструкцию; ZIP не нужно отправлять
команде `/upload_plugin`, которая принимает Python-файл.

Если установлена версия 0.1.0, замените её `claude_rental_plugin.py` новым файлом
при остановленном Cardinal. Старые `plugins/rental.py` и `plugins/remail.py`
готовой сборке больше не нужны: переместите их за пределы `plugins/`, чтобы
Cardinal не пытался загружать их как отдельные плагины. Базу и настройки сохраните.
UUID плагина остаётся прежним. Не устанавливайте две копии под разными именами.

## Настройка через меню

- **Добавить аккаунт** — введите почту, затем персональную ссылку Remail целиком.
  Адрес почты должен точно совпадать с `email` внутри ссылки. Сообщение со ссылкой
  удаляется по возможности, ссылка не повторяется в ответах и логах плагина.
  Ввод происходит в обычном личном чате Telegram с вашим ботом, не в секретном чате.
- **Аккаунты** — список с пагинацией; откройте аккаунт для просмотра статуса,
  лимитов и текущего заказа. Кнопка **Проверить Remail** показывает только число
  писем и не выдаёт покупателю никаких кодов.
- **Исключить из пула / Вернуть в пул** — запретить или разрешить будущие выдачи
  аккаунта. Возврат в пул не обходит проверку лимитов и сессий. Текущая аренда
  не прерывается. Запрет сохраняется после перезапуска.
- **Отправители Claude** — точные адреса из настоящих писем входа, через запятую.
  После изменения перезапустите Cardinal, если используется Claude-адаптер.
- **Название лота** — вставьте полное название вашего лота. Плагин будет искать
  точное совпадение без учёта регистра. Предустановленное правило уже распознаёт
  предоставленный ранее лот Claude PRO на 5 часов.
- **Срок аренды** — целое число часов, изначально 5. Бонус за отзыв автоматически
  не начисляется. По умолчанию количество товара не умножает срок.
- **Аренды** — последние 20 записей. Время завершения показывается в UTC.
- **Пауза / запуск** — управляет только новыми выдачами. При паузе обработка
  уже начатых аренд и проверка истечения сроков продолжаются.

Меню доступно только пользователям, авторизованным в Cardinal, и только в личных
чатах. Покупатели FunPay не имеют доступа к этой панели.

## Где лежат данные

При первом запуске создаются:

```text
storage/claude_rental/config.json
storage/claude_rental/rentals.sqlite3
```

Существующая конфигурация не заменяется при установке. В существующую базу
добавляется поле ручного исключения аккаунта; аккаунты и аренды сохраняются.
Перед обновлением сохраняйте резервную копию при остановленном Cardinal.
Токены Remail находятся в базе: ограничьте доступ к серверу и резервным копиям.

## Подключение Claude

В `config.json` поле `claude_provider_file` пока пустое. Когда будет реализован
и проверен модуль Claude, укажите его путь на сервере и перезапустите Cardinal.
Модуль должен предоставлять `create(config)` и методы `request_login`, `usage`,
`revoke_all`, описанные в `README.md`. Токен Remail не заменяет этот модуль.
Запросы к Claude и успех выхода из сессий плагин не имитирует.

Новый аккаунт остаётся в `quarantine`, пока не подтверждены отзыв прежнего
доступа и реальные лимиты. Отсутствие данных означает запрет выдачи.

После подключения отключите штатную автовыдачу Cardinal для тех же лотов,
чтобы она не отправляла товар параллельно. Запускайте один экземпляр плагина
на базу. Ожидание письма идёт в фоновом потоке. Операции внешнего адаптера
выполняются последовательно; проверка окончания аренды может задержаться на
время текущего запроса или ожидания письма. Это не механизм мгновенного отзыва.

Пауза новых выдач через меню сохраняет обработку активных аренд. Отключение
самого плагина в Cardinal или остановка Cardinal прекращает фоновые проверки;
не используйте это вместо паузы при действующих арендах.
Заказы, полученные во время паузы, ошибки выдачи и очередь, прерванная остановкой,
требуют ручной проверки — автоматического восстановления очереди пока нет.

## Проверки

Совместимость проверяется загрузчиком и Telegram-интерфейсами из предоставленного
архива Cardinal 0.1.17.15. В тестах отправка сообщений заменена локальной
имитацией: реальные покупатели и Telegram-аккаунты не затрагиваются. Сквозной
запуск с настоящими учётными данными FunPay, Remail и Claude пока не проверен.

Команды для разработчика:

```sh
python build_plugin.py
python -m unittest -v
```

Для дополнительных проверок настоящего загрузчика Cardinal установите его
зависимости и задайте `CARDINAL_SOURCE` — путь к распакованному Cardinal 0.1.17.15.
Запустите `python -m unittest -v test_cardinal_integration`.
