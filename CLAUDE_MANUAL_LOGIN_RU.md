# Windows: обычный Chrome или Edge для первого входа

В 0.4.2 единый запуск — `tools/claude_account.cmd`, пункт 1. Если тестовый
профиль остался в режиме check, после вашего подтверждения закрывается только
его браузер и открывается ручной вход. Профиль и личные браузеры сохраняются.
Запросите новое письмо в ручном окне и вставьте туда полную ссылку, включая #.


Если обычный Edge выполняет вход, а тестовый профиль повторяет Cloudflare даже
без режима проверки, можно сбросить его данные сайтов. Только в окне тестового
профиля нажмите **Ctrl+Shift+Delete**, выберите **За всё время**, оставьте только
cookies/данные сайтов и кэш, снимите остальные галочки. После очистки выполните
один ручной вход. Это сбросит входы в сайты именно этого профиля. В пользовательском
тесте очистка восстановила вход; универсальным решением она не является.

Если Claude открывается в обычном браузере, а Chromium из инструмента зациклен
на проверке Cloudflare, используйте этот запуск для ручного входа. Он открывает
установленный Chrome или Edge с отдельным профилем аккаунта. Ручной браузер запускается без удалённого управления. Если он остался
в режиме проверки, Playwright используется только для его закрытия после подтверждения. Проверка Cloudflare
остаётся проверкой самого сайта; успешное прохождение не гарантируется.

## Что сделать

1. Закройте окно Chromium с бесконечной проверкой и окно прежнего инструмента.
2. Скачайте [архив для ручного входа](https://github.com/chifirokxwolf/-/raw/refs/heads/claude-rental-stability-0.4.2/dist/claude-windows-login-0.4.2.zip).
3. В Проводнике нажмите правой кнопкой по ZIP → **Извлечь всё → Извлечь**.
   Откройте извлечённую обычную папку. Не запускайте файлы из окна ZIP.
4. Скопируйте папку **tools** из архива в папку Cardinal рядом с **main.py**.
   База, настройки и файл плагина не меняются; перезапуск Cardinal не требуется.
5. Из папки **Cardinal/tools** запустите **claude_account.cmd** и выберите **1**.
   Нужен именно этот новый файл. Старый **open_claude_session.cmd** запускает
   прежний Playwright Chromium. Установка через **setup_claude_browser.cmd**
   для нового способа не нужна.
6. Введите ID тестового аккаунта из меню **Аккаунты** и нажмите Enter.
7. Выберите номер браузера, в котором Claude у вас уже открывается.
8. Войдите в открывшемся окне по почте аккаунта и коду Remail. Если письмо содержит
   ссылку, откройте её в этом же отдельном окне, чтобы вход попал в нужный профиль.
9. После входа закройте окно браузера крестиком. Повторите запуск нового CMD,
   выберите тот же ID и тот же браузер, проверьте сохранение входа.

Профили лежат в `storage/claude_rental/browser_profiles/<ID>/chrome-manual/`
или `edge-manual/`. Профили Chrome и Edge, разных аккаунтов и старого инструмента
раздельны. Обычные личные профили браузеров не копируются и не изменяются.
Не удаляйте папку `storage` и не присылайте профили, cookies или коды входа.

Если и новое окно зацикливается на проверке, не запускайте автоматические
повторные попытки. Откройте **«Устранение неполадок»** на странице проверки.
Убедитесь, что браузер обновлён, а системные дата и время Windows правильные.
Сравнение с обычным браузером относится к той же сети; разные профили могут
получать разные проверки. При сохранении ошибки сообщите поддержке Claude
время проблемы и Ray ID со страницы.

Это подготовка сессии владельца. Сам факт ручного входа не подключает
Claude-адаптер, не проверяет лимиты и не обеспечивает автоматический кик.
При последующем подключении автоматизации сайт может снова запросить проверку.
Следующий шаг — проверить реальные страницы использования и «Выйти везде»
на тестовом аккаунте без действующей аренды, включая отзыв Claude Code.

Поиск браузера, выбор профиля и запуск проверяются локальными тестами с
имитацией Windows. Настоящая проверка Cloudflare и вход на Windows проверяются
на вашем компьютере; в среде разработки Windows нет.
